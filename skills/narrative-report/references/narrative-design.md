# ナラティブを設計する

ナラティブは事実を選び、意味を与えるため、書き始める前に視点と中心となる変化を定める。整った物語に見せることより、読者が状況・判断・未来の関係を正確に理解できることを優先する。

## 設計の手順

### 1. 読者と目的を定める

- 誰が読むのか。読者は何を知り、何を判断できるようになればよいか。
- 共有したいのは、状況認識、戦略、変革の必要性、選択肢のいずれか。
- 意思決定や行動を求めるのか。それとも理解・議論の土台を作るのか。

### 2. 根拠と解釈を分ける

材料を、少なくとも次の区分で整理する。

- 確認済みの事実・データ
- 出典や関係者が示す見解
- レポート側の解釈と推論
- 予測、目標、願望
- 未確認の前提と不確実性

解釈を事実のように見せたり、目標を確定した未来のように書いたりしない。必要な根拠が足りない場合は、ナラティブを強めるのではなく、確認事項や留保を明らかにする。

### 3. 中心となる変化を選ぶ

読者が理解する必要のある変化や緊張を一つ中心に置く。複数のテーマがある場合は主従をつけ、すべてを一つの大きな変革物語に束ねない。

例:

- 顧客の期待が変わり、従来の価値提供とのずれが広がっている。
- 成長は続いているが、その仕組みが次の段階では制約になる。
- 新しい技術が可能性を広げる一方、信頼や運用の条件を厳しくする。

### 4. ナラティブの筋を一文で仮置きする

次の型は考えを整理する作業用であり、そのまま本文に置くテンプレートではない。

> **〈状況〉**に**〈変化・緊張〉**が生じている。これは**〈意味〉**を持つため、**〈目指す状態〉**に向けて**〈関係者の選択・役割〉**を考える必要がある。

一文にできない場合は、情報を足す前に、中心となる変化・読者・目的が定まっているか見直す。

### 5. 読者に合う順序へ展開する

状況から未来へ時系列で語る方法だけに限らない。たとえば、次のような流れを使い分ける。

- **変化起点**: 何が変わったか → なぜ重要か → 何を選ぶか
- **判断起点**: 問い・選択肢 → 判断軸 → 根拠 → 影響と次の一歩
- **未来起点**: 目指す状態 → 現状との差 → 道筋 → 関係者の役割
- **現状認識起点**: 現状 → 既存の見方とのずれ → 新しい解釈 → 含意

この流れをそのまま固定目次にしない。問い、証拠、読者の読み方に合わせて入れ替えたり、一部を省いたりする。

### 6. 関係者の役割を具体化する

読者や関係者を、説得されるだけの観客として描かない。誰が決定権・実行責任・影響を持つのかを区別する。全員が同じ価値観や利害を持つと仮定せず、参加できる選択と現実の制約を示す。
