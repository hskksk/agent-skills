# D2 の全体像

図を書く前にこのファイルを読む。ここには毎回使う判断だけを置く。構文の正本は下の詳細ファイルで、必要なものだけを開く。色が何を意味するか、どのコマンドで検証するかは、このスキルの外である。

出典は [D2 の公式ツアー](https://d2lang.com/tour/) である。

| ファイル | 正本にしていること | いつ開くか |
| --- | --- | --- |
| `layout.md` | エンジン、`d2-config`、方向、寸法、題と `near` | レイアウトや題を決めるとき |
| `legend.md` | `d2-legend` | 凡例を置くとき |
| `connections.md` | キー、コンテナ、親 `_`、接続、矢じり | 図形を繋ぐとき |
| `shapes.md` | 形の一覧、`sql_table`、`class`、シーケンス、アイコン | 形を選ぶとき |
| `text.md` | 引用、改行、markdown、`${}`、コメント | ラベルや変数を書くとき |
| `style.md` | `style` の値、クラス、グロブ | 塗りや線を指定するとき |

## レイアウト

D2 の既定エンジンは `dagre` である。このスキルでは、ファイル先頭の `d2-config` で `layout-engine: elk` を指定する。`--layout` と `D2_LAYOUT` はファイル内の設定より優先される。方向、題、寸法、エンジンごとの制限は `layout.md` が正本である。

## タイトル

題は markdown ブロックを `near: top-center` に置く。`title: 文言` は上に固定された題にならず、キーが `title` の図形になる。書き方は `layout.md` が正本である。

## 凡例

凡例は `vars` の `d2-legend` で作る。端の図形の消し方と見出しの変更は `legend.md` が正本である。破線や透明度の取りうる値は `style.md` が正本である。

## コンテナの外から中を指す

接続はラベルではなくキーを指す。未宣言のキーはその場に新しい図形になる。コンテナの外からは完全修飾名を使い、親は `_` で指す。同じコンテナの中ではプレフィックスを省く。書き方は `connections.md` が正本である。

## 形

既定の `shape` は `rectangle` である。`sql_table`、`class`、`sequence_diagram` はそれぞれ専用の中身を持つ。一覧と書き方は `shapes.md` が正本である。形と業務上の意味の対応は、呼び出し側の規約に従う。

## ラベル

置換は `${path}` である。引用なしと二重引用符の、`${` で始まらない `$` はコンパイルできない。単引用符は置換を展開しない。改行、markdown、変数のスコープは `text.md` が正本である。
