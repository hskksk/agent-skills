# Phase 2 レポート三層構造ガイド

検証・構造化型レポート（Phase 2）の正本。L1（概要）・L2（本文）・L3（付録）の役割を分け、読者が**答え**と**根拠**を一度で把握できるようにする。

## 三層の役割

| 層 | 見出し例 | 役割 |
| --- | --- | --- |
| **L1** | `## 概要` | 答えの一文、判断の軸、位置づけ、3つの主張、調査範囲（5〜8文） |
| **L2** | `## <番号>. <名詞> — <主張>` | 各主張を根拠・事例・反論処理で展開。見出しは結論の言い切り |
| **L3** | `## 付録: 出典一覧` | `[n]` 脚注に対応する一次資料・データ・補足 |

L2 の各章は、L1 で列挙した3つの主張と1対1で対応させる（順序・番号を揃える）。

## L1 概要の必須要素（この順で含める）

1. **答え（一文）** — 依頼の問いに対する結論。
2. **軸** — 比較・判断に使った観点（例: コスト / 可用性 / 運用負荷）。
3. **位置づけ** — 推奨がどの選択肢・シナリオに当たるか。
4. **3つの主張** — 答えを支える論点（箇条書き3点）。L2 の章見出しの骨子になる。
5. **調査範囲** — 期間、地域、対象システム・資料の種類。

## `## 全体像`（論理構造図）

Mermaid で **問い → 軸 → 分かったこと（主張） → 答え** の流れを示す。L1 の3主張が図上で答えに集約されること。

## L2 本文（主張型見出し）

- 見出し形式: `## <番号>. <対象名詞> — <主張の要約>`
- 見出しだけ読んで結論が追えること（叙述見出しは避ける）。
- 各章の中身: 主張の根拠 → 具体例・データ → 限界・反論への一言。
- 本文中の根拠は `[n]` で L3 に接続する。

## その他の必須セクション

- **`## 背景・歴史 — <経緯の主張>`** — 答えが妥当な文脈（なぜ今この判断か）。
- **`## まとめ — 要点リスト`** — 決定事項・持ち帰り主張の箇条書き（L1 の答えと矛盾しない）。

## L3 付録

- 見出し: `## 付録: 出典一覧`
- `[n]` ごとに: 出典名、URLまたは文献情報、該当データの要約（1行でも可）。

- [ ] L2 見出しは言い切りで、3章が3主張に対応
- [ ] 全体像の Mermaid が問いから答えまでつながっている
