# 日本語で書く

日本語の文章を書く、英語から訳す、読みにくさを直すときに使う。文と語の正本は `references/japanese.md` である。本文を書く前と、直しに入る前に、そのファイルを最後まで読む。第1部を先に、第2部を次に。

## いつ使うか

- 日本語の技術文、レポート、記事、ドキュメントを書く
- 英語の文章や英語の思考を日本語にする
- 既存の日本語が直訳調、硬い、読みにくいと言われたときに直す

英語だけの成果物には使わない。

## 手順

1. `references/japanese.md` を読む。
2. 初稿を書く。作業用の語は読者向けの本文に出さない。
3. 第1部で直訳を検出する。無生物主語のまま、同じ分野の日本語で見た記憶がない動詞、元の英語が浮かぶ言い回し、辞書の意味で絵が成立しない比喩を止める。1.3 と 1.8 の表は型として使い、本文を検索して残っていないか確かめる。
4. 第2部で文を整える。修飾は係り先の近くに置く。簡潔にするときは 2.6 の順序（結論、一文一義、名詞を動詞へ、重複を削る、なくても意味が変わらない語を削る）に従う。
5. 直したあと、置き換え表の直訳語と、危険な語尾（「〜化」「〜性」「〜を行う」「〜をもたらす」）が残っていないかもう一度見る。定着した術語は残す。

## このファイルが扱わないこと

`references/japanese.md` が言及する `prose-style.md` は、このスキルには含まれない。段落の論証順はここでは規定しない。段落頭の接続表現は japanese.md の 2.7 までを使う。

1.9 の「前重心」「価値の中心」などは、出典スキルの作業語である。読者向けの見出しと本文には出さない。

2.9 の表記は、このカタログに既存記事があるという意味ではない。固有名は原文のまま、和文と英数字の間は半角スペース、年月日は詰める、という規則として適用する。
