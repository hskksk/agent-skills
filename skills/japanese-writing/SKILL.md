# 日本語で書く

日本語の文章を書く、英語から訳す、読みにくさを直すときに使う。文と語の正本は `references/japanese.md` である。本文を書く前と、直しに入る前に、そのファイルを最後まで読む。第1部を先に、第2部を次に。

## いつ使うか

- 日本語の技術文、レポート、記事、ドキュメントを書く
- 英語の文章や英語の思考を日本語にする
- 既存の日本語が直訳調、硬い、読みにくいと言われたときに直す

英語だけの成果物には使わない。

## 手順

1. `references/japanese.md` を読む。
2. 初稿を書く。制作用のメタ語は読者向けの本文に出さない（1.9）。
3. 第1部で直訳を検出する。1.2 の三段階（絵が崩れる／文脈で許容／そのまま）で強さを決める。1.3 の表は短い言い換えの型。全部を長い和文に広げない。
4. 第2部で文を整える。修飾は係り先の近くに置く。語種は 2.5 のとおり、CS の術語を無理に和語にしない。簡潔にするときは 2.6 の順序に従う。
5. 直したあと、1.3「直すことが多い」の語と、1.8 の空 rhetoric・比喩の借り語、危険な語尾（連続する「〜化」「〜の実施」「〜を行う」）を見る。1.3「定着した言い回し」（重要なのは、本稿は〜、可能にする など）は削らない。

## このスキルが扱わないこと

段落全体の論証設計や、長文レポート固有の構成テンプレートは含めない。段落頭の接続は `references/japanese.md` の 2.7 まで。
